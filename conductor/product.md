# Product Definition

**Product Name:** Workshop Pulse

**Vision:**
Web app for collecting real-time workshop feedback via anonymous polls.
Admins create workshops + AI-generated polls; attendees scan a QR, vote
with one tap, no account needed. Admins see live stats and AI sentiment
insights to close the feedback loop in minutes, not days.

**Why this matters:**
Traditional post-event surveys arrive too late and complete too rarely.
Anonymous one-tap voting during the session captures honest feedback while
context is fresh, and AI-generated questions remove facilitator bias.
